# 요구사항 정리

## 문서 목적

이 문서는 InterviewRoom v1에서 사용자가 할 수 있어야 하는 일을 정리한다.

요구사항은 구현 방식이 아니라 사용자 행동과 기능 범위를 기준으로 작성한다. v1은 면접 질문 CRUD 완성을 목표로 하며, 범위가 커지지 않도록 질문 관리에 필요한 최소 기능만 포함한다.

## v1 목표

InterviewRoom v1의 목표는 사용자가 면접 질문을 등록하고, 조회하고, 수정하고, 삭제할 수 있는 기본 흐름을 완성하는 것이다.

사용자는 면접 준비 과정에서 수집한 예상 질문과 실제 면접 질문을 기록할 수 있어야 한다. 또한 각 질문을 카테고리, 난이도, 질문 유형으로 구분해 최소한의 기준으로 정리할 수 있어야 한다.

v1은 면접 질문 관리 자체에 집중하며, 계정 기능, 탐색 기능, 복습 기능, AI 기능, 배포는 포함하지 않는다.

## 기능 요구사항

### 질문 등록

사용자는 새로운 면접 질문을 등록할 수 있어야 한다.

질문을 등록할 때 사용자는 질문 내용을 입력할 수 있어야 한다. 또한 질문을 정리하기 위해 카테고리, 난이도, 질문 유형을 선택할 수 있어야 한다.

질문 유형은 예상 질문과 실제 면접 질문 중 하나로 선택할 수 있어야 한다.

### 질문 조회

사용자는 등록된 면접 질문 목록을 확인할 수 있어야 한다.

목록에서는 사용자가 등록한 질문을 목록 형태로 확인할 수 있어야 한다. v1에서는 검색, 페이징, 정렬, 필터링 없이 기본 목록 조회만 제공하는 범위로 한정한다.

사용자는 목록에서 특정 질문을 선택해 상세 내용을 확인할 수 있어야 한다.

상세 조회에서는 선택한 질문의 내용과 분류 정보를 확인할 수 있어야 한다.

### 질문 수정

사용자는 등록된 면접 질문을 수정할 수 있어야 한다.

질문을 수정할 때 사용자는 질문 내용을 변경할 수 있어야 한다. 또한 카테고리, 난이도, 질문 유형도 필요에 따라 다시 선택할 수 있어야 한다.

수정 대상은 이미 등록된 면접 질문으로 한정한다.

### 질문 삭제

사용자는 더 이상 필요하지 않은 면접 질문을 삭제할 수 있어야 한다.

삭제 대상은 이미 등록된 면접 질문으로 한정한다. 삭제된 질문은 v1의 질문 목록과 상세 조회 대상에서 제외되어야 한다.

v1에서는 삭제 이력 관리, 복구, 보관함 기능은 포함하지 않는다.

### 질문 분류

사용자는 면접 질문을 등록하거나 수정할 때 카테고리, 난이도, 질문 유형을 선택할 수 있어야 한다.

카테고리는 다음 항목 중 하나를 선택한다.

- Java
- Spring
- JPA
- Database
- Network
- OS
- Project

난이도는 다음 항목 중 하나를 선택한다.

- 쉬움
- 보통
- 어려움

질문 유형은 다음 항목 중 하나를 선택한다.

- 예상 질문
- 실제 면접 질문

v1의 분류 기준은 위 항목으로 제한한다. 태그, 사용자 정의 카테고리, 다중 분류, 필터링은 v1 범위에 포함하지 않는다.

## 입력 조건

사용자는 면접 질문을 등록하거나 수정할 때 질문 내용을 입력할 수 있어야 한다.

사용자는 질문을 등록하거나 수정할 때 카테고리, 난이도, 질문 유형을 선택할 수 있어야 한다.

카테고리는 Java, Spring, JPA, Database, Network, OS, Project 중 하나여야 한다.

난이도는 쉬움, 보통, 어려움 중 하나여야 한다.

질문 유형은 예상 질문, 실제 면접 질문 중 하나여야 한다.

v1에서는 태그, 검색어, 복습 상태, 즐겨찾기 여부, 학습 자료 정보, AI 답변 정보는 입력 대상으로 다루지 않는다.

## 예외 상황

사용자가 질문 내용을 입력하지 않은 경우, 질문 등록 또는 수정이 완료되지 않아야 한다.

사용자가 카테고리, 난이도, 질문 유형 중 필요한 분류 값을 선택하지 않은 경우, 질문 등록 또는 수정이 완료되지 않아야 한다.

사용자가 존재하지 않는 질문을 조회하려는 경우, 해당 질문을 확인할 수 없어야 한다.

사용자가 존재하지 않는 질문을 수정하려는 경우, 수정이 완료되지 않아야 한다.

사용자가 존재하지 않는 질문을 삭제하려는 경우, 삭제가 완료되지 않아야 한다.

v1에서는 위 상황을 기능 범위 수준에서만 정의한다. 구체적인 화면 문구나 처리 방식은 이 문서에서 다루지 않는다.

## v1 완료 기준

v1은 다음 요구사항이 충족되었을 때 완료된 것으로 본다.

- 사용자가 면접 질문을 등록할 수 있다.
- 사용자가 등록된 면접 질문 목록을 확인할 수 있다.
- 사용자가 특정 면접 질문의 상세 내용을 확인할 수 있다.
- 사용자가 등록된 면접 질문을 수정할 수 있다.
- 사용자가 등록된 면접 질문을 삭제할 수 있다.
- 사용자가 질문 등록과 수정 과정에서 카테고리를 선택할 수 있다.
- 사용자가 질문 등록과 수정 과정에서 난이도를 선택할 수 있다.
- 사용자가 질문 등록과 수정 과정에서 질문 유형을 선택할 수 있다.
- 질문 유형은 예상 질문과 실제 면접 질문으로 구분된다.
- v1에서 제외하기로 한 요구사항이 포함되지 않는다.

## v1에서 제외하는 요구사항

다음 요구사항은 v1 범위에 포함하지 않는다.

- 사용자가 회원가입할 수 있어야 한다.
- 사용자가 로그인할 수 있어야 한다.
- 사용자가 질문에 태그를 추가할 수 있어야 한다.
- 사용자가 질문을 검색할 수 있어야 한다.
- 사용자가 질문 목록을 페이징해서 볼 수 있어야 한다.
- 사용자가 질문의 복습 상태를 관리할 수 있어야 한다.
- 사용자가 질문을 즐겨찾기할 수 있어야 한다.
- 사용자가 학습 자료를 관리할 수 있어야 한다.
- 사용자가 AI 답변을 생성할 수 있어야 한다.
- 사용자가 모의 면접 Agent를 사용할 수 있어야 한다.
- 사용자가 통계를 확인할 수 있어야 한다.
- 사용자가 알림을 받을 수 있어야 한다.
- 사용자가 배포된 서비스 환경에서 사용할 수 있어야 한다.

위 요구사항은 v1 이후 검토할 수 있지만, v1 완료 전에는 추가하지 않는다. v1의 요구사항은 면접 질문 CRUD와 최소 분류 기준에 한정한다.

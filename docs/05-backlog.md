# Backlog

## 문서 목적

이 문서는 InterviewRoom v1 이후에 검토할 수 있는 기능 후보를 정리한다.

v1의 목표는 면접 질문 CRUD 완성이다. 따라서 이 문서에 있는 기능은 v1에서 구현하지 않고 backlog로만 관리한다.

Backlog에 기록된 기능은 향후 확장 후보일 뿐이며, 실제 구현 여부와 우선순위는 v1 완료 이후 다시 판단한다.

v2, v3 같은 번호는 기능 후보를 분류하기 위한 임시 구분이다. 확정된 구현 순서나 일정으로 보지 않는다.

## v2 후보: 질문 탐색 기능

질문 탐색 기능은 등록된 면접 질문이 많아졌을 때 원하는 질문을 더 쉽게 찾기 위한 기능이다.

후보 기능은 다음과 같다.

- 검색
- 페이징
- 정렬
- 카테고리별 필터링
- 난이도별 필터링
- 질문 유형별 필터링

v1에서 제외하는 이유는 질문 CRUD 흐름을 먼저 완성하는 것이 더 중요하기 때문이다. v1에서는 질문 목록을 확인할 수 있는 수준까지만 다루고, 탐색 편의 기능은 질문 데이터가 충분히 쌓인 뒤 검토한다.

## v3 후보: 복습 관리 기능

복습 관리 기능은 사용자가 다시 확인해야 할 질문을 관리하기 위한 기능이다.

후보 기능은 다음과 같다.

- 복습 상태 관리
- 즐겨찾기
- 마지막 복습일
- 다시 볼 질문 표시
- 복습 알림

v1에서 제외하는 이유는 복습 기능이 질문 CRUD 이후의 학습 관리 영역이기 때문이다. v1에서는 질문을 기록하고 관리하는 기본 흐름에 집중하고, 복습 기준이나 알림은 이후에 검토한다.

## v4 후보: 학습 자료 관리 기능

학습 자료 관리 기능은 면접 준비에 사용한 책, 강의, 문서 등을 정리하기 위한 기능이다.

후보 기능은 다음과 같다.

- 책/강의 학습 자료 관리
- 학습 자료와 면접 질문 연결

v1에서 제외하는 이유는 학습 자료가 면접 질문 CRUD와 별도의 관리 대상이기 때문이다. 먼저 질문 자체를 안정적으로 관리할 수 있어야 하며, 학습 자료와의 연결은 그 이후에 검토한다.

## v5 후보: 회원 기능

회원 기능은 사용자별로 질문을 분리하고 개인화된 관리를 제공하기 위한 기능이다.

후보 기능은 다음과 같다.

- 회원가입
- 로그인
- 내 질문 관리

v1에서 제외하는 이유는 계정 기능이 들어가면 v1 범위가 크게 늘어나기 때문이다. v1에서는 단일 사용자 기준으로 면접 질문 CRUD를 완성하는 데 집중한다.

## v6 후보: 모의 면접 Agent

모의 면접 Agent는 저장된 질문을 바탕으로 실제 면접처럼 연습할 수 있게 하는 기능이다.

후보 기능은 다음과 같다.

- 모의 면접 Agent
- 면접 결과 리포트

v1에서 제외하는 이유는 모의 면접 기능이 질문 관리 이후의 고도화 기능이기 때문이다. v1에서는 질문을 등록하고 조회하고 수정하고 삭제하는 기본 흐름만 다룬다.

## v7 후보: AI 피드백 기능

AI 피드백 기능은 사용자의 면접 준비를 보조하기 위한 기능이다.

후보 기능은 다음과 같다.

- AI 답변 피드백
- AI 꼬리 질문 생성
- AI 예상 질문 생성

v1에서 제외하는 이유는 AI 기능이 질문 CRUD보다 범위와 복잡도가 크기 때문이다. v1에서는 AI를 사용하지 않고, 질문 관리 기능이 완성된 이후에 필요성을 검토한다.

## 나중에 고려할 기능

다음 기능은 v1 이후에도 바로 포함하기보다 필요성이 명확해졌을 때 검토한다.

- 태그
- 통계 대시보드
- 배포
- 문서화 고도화

태그는 질문 분류를 유연하게 만들 수 있지만, v1의 카테고리, 난이도, 질문 유형만으로도 최소 정리는 가능하다.

통계 대시보드는 충분한 질문 데이터와 사용 기록이 쌓인 뒤 의미가 있다.

배포와 문서화 고도화는 프로젝트를 외부에서 사용하거나 운영할 필요가 생겼을 때 검토한다.

## v1 중 절대 구현하지 않을 기능

v1 진행 중에는 다음 기능을 구현하지 않는다.

- 검색
- 페이징
- 정렬
- 카테고리별 필터링
- 난이도별 필터링
- 질문 유형별 필터링
- 복습 상태 관리
- 즐겨찾기
- 마지막 복습일
- 다시 볼 질문 표시
- 책/강의 학습 자료 관리
- 학습 자료와 면접 질문 연결
- 회원가입
- 로그인
- 내 질문 관리
- 태그
- 통계 대시보드
- 복습 알림
- AI 답변 피드백
- AI 꼬리 질문 생성
- AI 예상 질문 생성
- 모의 면접 Agent
- 면접 결과 리포트
- 배포
- 문서화 고도화

v1에서는 면접 질문 CRUD만 구현 대상으로 본다. Backlog의 기능은 v1 완료 전까지 구현 대상으로 끌어오지 않는다.

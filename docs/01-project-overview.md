# 프로젝트 개요

## 프로젝트명

InterviewRoom

## 한 줄 소개

개발자 면접 준비 과정에서 예상 질문과 실제 면접 질문을 기록하고, 카테고리와 난이도별로 정리할 수 있도록 돕는 면접 질문 관리 서비스

## 프로젝트 목적

InterviewRoom의 현재 목적은 큰 포트폴리오 서비스를 만드는 것이 아니라, 작은 CRUD 프로젝트를 끝까지 완성하면서 Spring/JPA 기본기를 다지는 것이다.

v1에서는 면접 질문을 등록하고, 조회하고, 수정하고, 삭제하는 기본 흐름을 완성하는 데 집중한다. 기능을 많이 넣기보다 하나의 작은 도메인을 안정적으로 끝까지 구현할 수 있는 구조와 흐름을 잡는 것을 우선한다.

## 타겟 사용자

1차 사용자는 Java/Spring 백엔드 개발자로 취업을 준비하는 나 자신이다.

확장 사용자는 면접 질문을 노션, 메모장, 블로그 등에 흩어져 정리하는 취업 준비생이다.

## 문제 정의

개발자 면접을 준비하다 보면 예상 질문과 실제 면접에서 받은 질문이 여러 곳에 흩어지기 쉽다. 처음에는 메모장이나 노션만으로도 충분하지만, 질문이 늘어날수록 기준을 정해 정리하기 어려워진다.

InterviewRoom에서 해결하고 싶은 문제는 다음과 같다.

- 면접 질문이 여러 곳에 흩어져 관리된다.
- 질문이 많아질수록 카테고리별로 정리하기 어렵다.
- 질문의 난이도를 기준으로 정리하기 어렵다.
- 예상 질문과 실제 면접 질문을 구분하기 어렵다.
- 기록한 질문을 한곳에서 다시 확인하기 어렵다.

## 해결 방향

InterviewRoom은 면접 질문을 하나의 공간에 기록하고, 최소한의 분류 기준으로 정리할 수 있게 한다.

v1에서는 질문 자체를 관리하는 기본 기능에 집중한다. 각 질문은 카테고리, 난이도, 질문 유형을 함께 선택해 저장할 수 있도록 한다. 이를 통해 사용자는 예상 질문과 실제 면접 질문을 구분하고, 질문을 주제와 난이도 기준으로 정리할 수 있다.

복습 상태, 검색, 태그, 통계 같은 기능은 유용할 수 있지만 v1에서는 제외한다. 현재 단계에서는 기능 확장보다 면접 질문 CRUD를 끝까지 완성하는 것이 더 중요하다.

## v1 목표

v1 목표는 면접 질문 CRUD 완성이다.

사용자는 면접 질문을 등록하고, 목록에서 확인하고, 상세 내용을 조회하고, 필요한 경우 수정하거나 삭제할 수 있어야 한다.

## v1 핵심 기능

v1에서 포함하는 핵심 기능은 다음과 같다.

- 면접 질문 등록
- 면접 질문 목록 조회
- 면접 질문 상세 조회
- 면접 질문 수정
- 면접 질문 삭제
- 카테고리 선택
- 난이도 선택
- 질문 유형 선택

질문 유형은 다음 두 가지로 제한한다.

- 예상 질문
- 실제 면접 질문

## v1 제외 기능

v1에서는 다음 기능을 제외한다.

- 회원가입
- 로그인
- 태그
- 검색
- 페이징
- 복습 상태
- 즐겨찾기
- 학습 자료 관리
- AI 답변 생성
- 모의 면접 Agent
- 통계
- 알림
- 배포

## 향후 확장 방향

v1을 완료한 뒤에는 실제 사용 과정에서 필요성이 확인된 기능만 단계적으로 확장한다.

향후 확장 후보는 다음과 같다.

- 검색, 페이징, 정렬
- 카테고리, 난이도, 질문 유형별 필터링
- 복습 상태 관리
- 즐겨찾기
- 학습 자료 관리
- 회원가입과 로그인
- 모의 면접 Agent
- AI 답변 피드백
- 통계 대시보드
- 배포 및 문서화 고도화

단, 위 기능은 v1 범위에 포함하지 않는다. v1에서는 면접 질문 CRUD를 완성한 뒤, 실제로 불편함이 확인된 기능부터 추가한다.

## 프로젝트 진행 원칙

InterviewRoom은 작은 CRUD 프로젝트를 끝까지 완성하는 것을 우선한다.

프로젝트 진행 원칙은 다음과 같다.

- v1 범위를 면접 질문 CRUD로 제한한다.
- 기능을 늘리기보다 기본 흐름을 명확히 완성한다.
- Spring/JPA 기본기를 연습할 수 있는 구조를 우선한다.
- 처음부터 대규모 서비스를 전제로 설계하지 않는다.
- 필요성이 검증되지 않은 기능은 v1에 포함하지 않는다.
- 문서와 구현 범위가 서로 어긋나지 않도록 관리한다.

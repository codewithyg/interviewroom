# MVP 범위 정의

## MVP를 나누는 이유

InterviewRoom은 면접 질문을 한곳에 기록하고 관리하기 위한 프로젝트이다. 처음부터 많은 기능을 포함하면 핵심 흐름이 불명확해지고, 완성 기준도 흐려질 수 있다.

따라서 MVP v1은 면접 질문 CRUD 완성에만 집중한다. v1에서는 사용자가 면접 질문을 등록하고, 목록에서 확인하고, 상세 내용을 조회하고, 필요한 경우 수정하거나 삭제할 수 있는 최소 기능을 완성하는 것을 목표로 한다.

v1의 목적은 큰 서비스가 아니라 작고 명확한 질문 관리 흐름을 끝까지 완성하는 것이다. 검색, 로그인, AI 기능, 배포 등은 중요할 수 있지만 v1 완료 전에는 범위에 포함하지 않는다.

## MVP v1: 면접 질문 관리

### 목표

MVP v1의 목표는 면접 질문 관리의 기본 흐름을 완성하는 것이다.

사용자는 면접 준비 과정에서 수집한 예상 질문과 실제 면접 질문을 InterviewRoom에 기록할 수 있어야 한다. 각 질문은 최소한의 분류 기준을 통해 정리할 수 있어야 하며, 이후 다시 확인하거나 내용을 수정하거나 더 이상 필요하지 않은 질문을 삭제할 수 있어야 한다.

v1은 질문 관리 자체에 집중하며, 사용자 계정, 검색, 복습, AI, 통계 같은 확장 기능은 포함하지 않는다.

### 핵심 기능

v1에서 포함하는 핵심 기능은 다음과 같다.

- 면접 질문 등록
- 면접 질문 목록 조회
- 면접 질문 상세 조회
- 면접 질문 수정
- 면접 질문 삭제
- 카테고리 선택
- 난이도 선택
- 질문 유형 선택

질문 유형은 다음 두 가지로 제한한다.

- 예상 질문
- 실제 면접 질문

카테고리, 난이도, 질문 유형은 질문을 정리하기 위한 최소 분류 기준이다. v1에서는 이 기준을 복잡하게 확장하지 않고, 질문 CRUD 흐름 안에서 함께 선택할 수 있는 범위로만 다룬다.

### 완료 기준

MVP v1은 다음 상태가 되었을 때 완료된 것으로 본다.

- 사용자가 면접 질문을 등록할 수 있다.
- 등록된 면접 질문을 목록에서 확인할 수 있다.
- 목록에서 선택한 질문의 상세 내용을 확인할 수 있다.
- 기존 면접 질문의 내용을 수정할 수 있다.
- 더 이상 필요하지 않은 면접 질문을 삭제할 수 있다.
- 질문을 등록하거나 수정할 때 카테고리, 난이도, 질문 유형을 선택할 수 있다.
- 질문 유형은 예상 질문과 실제 면접 질문으로 구분된다.
- v1에서 제외하기로 한 기능이 범위에 추가되지 않는다.

완료 기준은 기능 범위의 완료 여부를 판단하기 위한 기준이다. 세부 구현 방식은 이 문서에서 다루지 않는다.

### v1에서 제외하는 기능

다음 기능은 v1 범위에 포함하지 않는다.

- 회원가입
- 로그인
- 태그
- 검색
- 페이징
- 복습 상태
- 즐겨찾기
- 학습 자료 관리
- AI 답변 생성
- 모의 면접 Agent
- 통계
- 알림
- 배포

위 기능들은 향후 확장 후보로 검토할 수 있지만, v1 완료 전에는 추가하지 않는다. v1의 범위는 면접 질문 CRUD와 최소 분류 기준에 한정한다.

## 향후 확장 후보

향후 확장 후보는 v1 이후 검토할 수 있는 기능 목록이다. 이 목록은 구현 약속이나 v1 범위가 아니며, 실제 필요성이 확인된 뒤 우선순위를 정한다.

### 질문 탐색 기능

질문이 많아졌을 때 원하는 질문을 더 쉽게 찾기 위한 기능이다.

후보 기능은 다음과 같다.

- 검색
- 페이징
- 정렬
- 카테고리별 필터링
- 난이도별 필터링
- 질문 유형별 필터링

v1에서는 질문 목록 조회만 포함하며, 탐색 기능은 질문 데이터가 충분히 쌓인 뒤 검토한다.

### 복습 관리 기능

면접 질문을 다시 학습하거나 확인하기 위한 관리 기능이다.

후보 기능은 다음과 같다.

- 복습 상태 관리
- 즐겨찾기

v1에서는 질문을 기록하고 관리하는 흐름에 집중한다. 특정 질문을 다시 봐야 하는지, 중요 질문으로 따로 표시해야 하는지는 v1 이후에 검토한다.

### 학습 자료 관리 기능

면접 준비에 사용한 책, 강의, 문서 등의 학습 자료를 관리하기 위한 기능이다.

후보 기능은 다음과 같다.

- 책 학습 자료 관리
- 강의 학습 자료 관리
- 기타 학습 자료 관리

v1에서는 학습 자료를 별도로 관리하지 않는다. 질문 자체를 관리하는 흐름이 먼저 완성된 뒤 확장 여부를 판단한다.

### 학습 자료와 면접 질문 연결

학습 자료와 면접 질문의 관계를 관리하기 위한 기능이다.

예를 들어 특정 질문이 어떤 책, 강의, 문서에서 비롯되었는지 연결할 수 있다. 이 기능은 학습 자료 관리 기능이 먼저 필요하므로 v1에는 포함하지 않는다.

### 회원 기능

사용자별로 질문 데이터를 분리하거나 개인화된 사용 경험을 제공하기 위한 기능이다.

후보 기능은 다음과 같다.

- 회원가입
- 로그인
- 사용자별 데이터 관리

v1에서는 회원 기능을 포함하지 않는다. 먼저 단일 사용자 기준으로 면접 질문 CRUD 흐름을 완성한다.

### 모의 면접 Agent

저장된 면접 질문을 기반으로 모의 면접을 진행하기 위한 기능이다.

이 기능은 질문 관리가 안정적으로 완성된 뒤 검토한다. v1에서는 모의 면접 진행, 대화형 질문, 면접 세션 관리는 포함하지 않는다.

### AI 피드백 기능

AI를 활용해 답변 품질을 높이기 위한 기능이다.

후보 기능은 다음과 같다.

- AI 답변 피드백
- AI 꼬리 질문 생성
- 면접 결과 리포트

v1에서는 AI 기능을 포함하지 않는다. 질문 관리의 기본 흐름이 완성된 이후, 실제 사용 과정에서 필요한 피드백 형태를 확인한 뒤 검토한다.

### 배포 및 문서화 고도화

서비스 운영과 외부 사용을 위한 확장 영역이다.

후보 기능은 다음과 같다.

- 배포
- 운영 환경 정리
- 문서화 고도화

v1에서는 배포를 목표로 하지 않는다. 먼저 로컬 개발 환경에서 면접 질문 CRUD를 완성하는 데 집중한다.

## 최종 진행 원칙

- v1은 반드시 작게 유지한다.
- v1의 목표는 면접 질문 CRUD 완성이다.
- v1 완료 전까지 새로운 기능을 추가하지 않는다.
- 카테고리, 난이도, 질문 유형은 최소 분류 기준으로만 다룬다.
- 향후 기능은 후보로만 정리하고, v1 범위에 포함하지 않는다.
- 기능 확장은 v1 완료 이후 실제 필요성이 확인된 경우에만 검토한다.
- 이 문서는 기능 범위를 정의하는 문서이며, 세부 구현 방식은 다루지 않는다.

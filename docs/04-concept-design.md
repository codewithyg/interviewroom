# 개념 설계

## 핵심 개념

InterviewRoom v1은 면접 질문 관리에만 집중한다.

v1에서 다루는 핵심 개념은 다음 네 가지이다.

- 면접 질문
- 카테고리
- 난이도
- 질문 유형

이 문서는 각 개념의 의미와 범위를 정리한다. 구현 방식, 내부 구조, 저장 방식, 외부 연결 방식은 다루지 않는다.

## 면접 질문

면접 질문은 InterviewRoom v1에서 관리하는 중심 개념이다.

사용자는 면접 준비 과정에서 기억해두고 싶은 질문을 면접 질문으로 기록한다. 면접 질문은 예상 질문일 수도 있고, 실제 면접에서 받은 질문일 수도 있다.

v1에서 면접 질문은 다음 행동의 대상이 된다.

- 등록
- 목록 조회
- 상세 조회
- 수정
- 삭제

면접 질문은 카테고리, 난이도, 질문 유형을 통해 최소한의 기준으로 구분된다. v1에서는 질문을 기록하고 다시 확인할 수 있는 기본 관리 흐름에 집중한다.

v1에서 면접 질문은 태그, 복습 상태, 즐겨찾기, 학습 자료, AI 답변, 통계와 연결하지 않는다.

## 카테고리

카테고리는 면접 질문이 어떤 주제에 속하는지 구분하기 위한 개념이다.

v1의 카테고리는 다음 항목으로 제한한다.

- Java
- Spring
- JPA
- Database
- Network
- OS
- Project

카테고리는 질문을 정리하기 위한 최소 분류 기준이다. 사용자는 면접 질문을 등록하거나 수정할 때 카테고리를 선택할 수 있다.

v1에서는 사용자 정의 카테고리, 다중 카테고리, 카테고리별 필터링은 다루지 않는다.

## 난이도

난이도는 면접 질문을 사용자가 느끼는 체감 수준에 따라 구분하기 위한 개념이다.

v1의 난이도는 다음 항목으로 제한한다.

- 쉬움
- 보통
- 어려움

난이도는 질문의 절대적인 평가 기준이 아니라, 사용자가 질문을 정리하고 다시 확인할 때 참고하기 위한 단순한 분류 기준이다.

v1에서는 난이도 자동 판정, 점수화, 단계 세분화, 난이도별 필터링은 다루지 않는다.

## 질문 유형

질문 유형은 면접 질문이 어떤 출처나 성격을 가지는지 구분하기 위한 개념이다.

v1의 질문 유형은 다음 두 가지로 제한한다.

- 예상 질문
- 실제 면접 질문

예상 질문은 면접 전에 준비하거나 학습 과정에서 정리한 질문이다.

실제 면접 질문은 사용자가 실제 면접 과정에서 받았거나, 실제 면접 사례로 기록해둘 필요가 있는 질문이다.

질문 유형은 면접 질문을 등록하거나 수정할 때 선택할 수 있다. v1에서는 질문 유형을 위 두 가지 외로 확장하지 않는다.

## v1에서 다루지 않는 개념

다음 개념은 v1에서 다루지 않는다.

- 사용자
- 로그인
- 태그
- 학습 자료
- 복습 기록
- 즐겨찾기
- 모의 면접 세션
- AI 피드백
- 통계

위 개념들은 InterviewRoom이 확장될 때 필요할 수 있지만, v1의 목표인 면접 질문 CRUD 완성과 직접적인 범위로 보지 않는다.

v1에서는 면접 질문을 개인 계정과 연결하지 않는다. 또한 질문을 태그로 확장하거나, 학습 자료와 연결하거나, 복습 이력으로 관리하지 않는다.

모의 면접 세션, AI 피드백, 통계는 질문 관리 흐름이 안정적으로 완성된 뒤 검토할 수 있는 확장 개념이다.

## 향후 확장 개념

v1 이후에는 실제 사용 과정에서 필요성이 확인된 개념만 단계적으로 검토한다.

향후 확장 후보가 될 수 있는 개념은 다음과 같다.

- 사용자별 질문 관리
- 태그 기반 질문 분류
- 학습 자료 관리
- 학습 자료와 면접 질문의 연결
- 복습 기록
- 즐겨찾기
- 모의 면접 세션
- AI 답변 피드백
- AI 꼬리 질문
- 면접 결과 통계

향후 확장 개념은 v1 범위에 포함하지 않는다. v1에서는 면접 질문, 카테고리, 난이도, 질문 유형만 핵심 개념으로 다룬다.

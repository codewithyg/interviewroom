## 한 줄 소개

> 개발자 면접 준비 과정에서 예상 질문과 실제 면접 질문을 기록하고, 카테고리와 난이도별로 정리할 수 있도록 돕는 면접 질문 관리 서비스입니다.

---

## 서비스 설명

InterviewRoom은 면접 준비 과정에서 정리한 예상 질문과 실제 면접에서 받은 질문을 한곳에 모아 관리하기 위한 개인 프로젝트입니다.

면접을 준비하다 보면 공부하면서 정리한 질문, 실제 면접에서 받은 질문, 다시 확인하고 싶은 질문이 계속 쌓입니다. 처음에는 메모장이나 노션으로도 충분하지만, 질문이 많아질수록 주제별로 분류하거나 난이도를 구분하기가 어려워집니다.

이 프로젝트는 그런 문제를 작게 풀어보기 위해 시작했습니다.
v1에서는 많은 기능을 한 번에 넣기보다, 면접 질문을 등록하고 조회하고 수정하고 삭제하는 기본 CRUD 흐름을 먼저 완성하는 것을 목표로 합니다.

현재는 기획 및 설계 문서화를 마쳤고, v1 구현을 준비하는 단계입니다.
백엔드 API를 우선 구현한 뒤, 이후 프론트엔드를 연결해 실제로 사용할 수 있는 Web 서비스 형태로 확장할 예정입니다.

---

## 프로젝트 문제의식

InterviewRoom은 다음과 같은 문제의식에서 출발했습니다.

* 면접 질문이 메모장, 노션, 블로그 등 여러 곳에 흩어져 관리된다.
* 질문이 많아질수록 Java, Spring, JPA, Database 등 카테고리별로 정리하기 어렵다.
* 질문의 난이도를 기준으로 구분하기 어렵다.
* 예상 질문과 실제 면접에서 받은 질문이 섞여 관리된다.
* 기록한 질문을 다시 확인하거나 복습하기 위한 기준이 부족하다.

검색, 복습 상태, 즐겨찾기, 모의 면접 같은 기능도 필요할 수 있습니다.
다만 v1에서는 범위를 키우지 않고, 면접 질문 CRUD와 최소한의 분류 기준을 먼저 완성하는 데 집중합니다.

## 기능 구성

### v1 목표 기능

v1에서는 먼저 Backend API 기준으로 면접 질문 CRUD 흐름을 완성합니다.
이후 Frontend 화면을 연결해 실제로 사용할 수 있는 Web 서비스 형태로 확장할 예정입니다.

| 기능          | 설명                                  | Backend API | Frontend |
| ----------- | ----------------------------------- | ----------- | -------- |
| 면접 질문 등록    | 새로운 면접 질문과 답변을 기록한다.                | 구현 예정       | 추후 연결 예정 |
| 면접 질문 목록 조회 | 등록된 면접 질문을 목록으로 확인한다.               | 구현 예정       | 추후 연결 예정 |
| 면접 질문 상세 조회 | 선택한 질문의 상세 내용과 답변을 확인한다.            | 구현 예정       | 추후 연결 예정 |
| 면접 질문 수정    | 등록된 질문 내용, 답변, 분류 정보를 수정한다.         | 구현 예정       | 추후 연결 예정 |
| 면접 질문 삭제    | 더 이상 필요하지 않은 질문을 삭제한다.              | 구현 예정       | 추후 연결 예정 |
| 카테고리 선택     | 질문의 주제를 Java, Spring, JPA 등으로 구분한다. | 구현 예정       | 추후 연결 예정 |
| 난이도 선택      | 질문의 난이도를 쉬움, 보통, 어려움으로 구분한다.        | 구현 예정       | 추후 연결 예정 |
| 질문 유형 선택    | 예상 질문과 실제 면접 질문을 구분한다.              | 구현 예정       | 추후 연결 예정 |

### 분류 기준

| 구분    | 값                                                 |
| ----- | ------------------------------------------------- |
| 질문 유형 | 예상 질문, 실제 면접 질문                                   |
| 카테고리  | Java, Spring, JPA, Database, Network, OS, Project |

### v1 제외 기능

아래 기능은 v1에서 구현하지 않습니다.
v1에서는 기능을 늘리기보다 면접 질문 CRUD를 끝까지 완성하는 데 집중합니다.

| 기능          | 제외 이유                                | 상태    |
| ----------- | ------------------------------------ | ----- |
| 회원가입        | 사용자별 데이터 분리는 v1 CRUD 완성 이후에 고려한다.    | v1 제외 |
| 로그인         | 인증/인가 흐름이 추가되면 v1 범위가 커지므로 제외한다.     | v1 제외 |
| 태그          | 초기에는 고정된 카테고리만으로 질문을 분류한다.           | v1 제외 |
| 검색          | 질문 목록 조회 이후 확장 기능으로 추가한다.            | v1 제외 |
| 페이징         | 질문 데이터가 많아지는 시점에 추가한다.               | v1 제외 |
| 복습 상태       | 단순 질문 관리가 완성된 뒤 복습 기능으로 확장한다.        | v1 제외 |
| 즐겨찾기        | 복습 관리 기능과 함께 추후 검토한다.                | v1 제외 |
| 학습 자료 관리    | 책/강의 관리 기능은 질문 CRUD 이후 별도 기능으로 확장한다. | v1 제외 |
| AI 답변 생성    | AI 기능은 기본 데이터 관리 흐름이 완성된 뒤 검토한다.     | v1 제외 |
| 모의 면접 Agent | 질문 데이터가 쌓이고 복습 기능이 정리된 이후 확장한다.      | v1 제외 |
| 통계          | 질문과 복습 데이터가 충분히 쌓인 이후 의미가 생긴다.       | v1 제외 |
| 알림          | 복습 일정 기능과 함께 추후 검토한다.                | v1 제외 |
| 배포          | v1 구현과 문서 정리 이후 진행한다.                | v1 제외 |

## 시스템 아키텍처

현재는 배포된 서비스가 아니라, 개발 환경을 기준으로 준비 중입니다.
Backend API를 우선 구현하고, 이후 Frontend를 연결해 Web 서비스 형태로 확장할 예정입니다.

```text
[User]
   |
   v
[Frontend Web App]
   |
   v
[Spring Boot Backend API]
   |
   v
[Home Server VM]
   |
   v
[MySQL Docker Container]
```

| 구성 요소                   | 설명                         | 상태       |
| ----------------------- | -------------------------- | -------- |
| Frontend Web App        | 사용자가 면접 질문을 관리하는 화면        | 추후 구현 예정 |
| Spring Boot Backend API | 면접 질문 CRUD 처리              | 구현 예정    |
| Home Server VM          | 개발용 DB를 운영하는 VM            | 구성 완료    |
| MySQL Docker Container  | InterviewRoom 개발용 MySQL DB | 구성 완료    |
| 배포 환경                   | 실제 서비스 배포 환경               | v1 이후 검토 |
